# BougtCam

Windows 11 向け・完全ローカル動作の常駐型 Web カメラ録画アプリ。
起動すると設定画面なしで自動的に最大解像度で録画を開始し、タスクトレイに常駐します。

## 配布物の構成

```
BougtCam/
  BougtCam.exe        … 本体（PyInstaller製、コンソール非表示）
  ffmpeg/ffmpeg.exe   … 同梱の録画エンジン
  _internal/          … Python ランタイム等
```

`BougtCam.exe` を実行するだけで動きます（インストール不要・管理者権限不要・ネットワーク不要）。

## 動作仕様

- **起動即録画**: 起動→カメラ検出→サポートモード列挙→最大画素数のモードで自動録画開始。
- **解像度選択**: DirectShow が返すモード一覧から (1) 最大画素数 (2) 同一画素数なら高FPS (3) 安定しやすいピクセル形式（mjpeg 優先）の順で選択。失敗時は順次フォールバックし、交渉結果はログに記録します。
- **保存先**: 既定 `C:\Users\bougt\video`（設定で変更可）。ファイル名 `YYYY-MM-DD_HH-MM-SS.mp4`、重複時は `_01` 連番。
- **耐障害性**: 録画中は断片化しにくい MKV で書き込み、正常停止/終了時に再エンコードなしで MP4 へ変換（リムックス）します。変換失敗時は MKV を削除せず残します。
- **タスクトレイ**: 右クリックで 録画開始/停止/状態表示/解像度表示/保存フォルダを開く/設定/終了。録画中はアイコンが赤になります。
- **バックグラウンド**: ウィンドウを閉じてもトレイに残り録画継続。最小化・他アプリ前面・仮想デスクトップ切替でも継続します。
- **障害対応**: ffmpeg 異常終了・出力停滞(15s)・ディスク残量不足を監視。カメラ切断時は切断を検出し、再接続されると新しいファイルで録画再開。二重起動はロックファイルで防止。
- **音声**: 既定オフ。設定で DirectShow マイクを有効化可能。
- **エンコーダ**: h264_nvenc → h264_qsv → h264_amf → libx264 の順に試行し、実際に出力が始まったものを採用。

## 設定・ログ

- 設定: `%LOCALAPPDATA%\BougtCam\config.json`
- ログ: `%LOCALAPPDATA%\BougtCam\logs\bougtcam-YYYYMMDD.log`

## ビルド

Windows 11 + Python 3.11 以上:

```
build\build.bat
```

仮想環境作成→依存インストール→ffmpeg(gyan.dev release-essentials)取得→PyInstaller で `dist\BougtCam\` を生成します。

開発実行（ソースから）: `pip install -r requirements.txt && python run.py`

## 既知の制約

- **復旧可能性の限界**: 録画は MKV 追記型のためプロセス異常終了時も直前までの映像は概ね再生可能ですが、強制終了・電源断直後の最後の数秒・コンテナの最終確定情報が失われることがあります。完全なデータ保護は保証しません。
- カメラアクセスは Windows のプライバシー設定（設定→プライバシー→カメラ）で許可が必要です。未許可時はデバイスが列挙されず「カメラ未検出」になります。
- 画面ロック中もプロセスは継続しますが、USB 省電力やドライバ仕様でカメラが切断される環境では録画が止まります（解除後に自動復帰）。
- 複数アプリからの同時カメラ占有はデバイス次第で失敗します。
- 4K 等高解像度では CPU/GPU 負荷が上がります。HW エンコーダ利用時でも環境によってはソフトウェアにフォールバックします。
